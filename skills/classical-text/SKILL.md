# 古籍校勘与整理规范

## 校勘四法（陈垣《校勘学释例》）

1. **对校**（最基本）：同书异本对读，校其异同。只校异同，不判断是非。
2. **本校**：以本书前后互证，找自相矛盾处，如纪年、地名、人名前后不一。
3. **他校**：以他书所引（类书如《太平御览》、史注、他籍）校本书。
4. **理校**：据文理、声韵、避讳、典章制度推断正误；无版本依据，须注明"理校"。

> 运用次序：先对校，次本校，再他校，理校最慎。凡径改处必须出校记。

## 校勘记体例

```
〔卷数·页数·行数〕原句文字：底本作"甲"，校本某（简称）作"乙"，据改/两存/存疑。
```

- 底本文字不动，异文记入校勘记——"存真"原则；确系讹误且理据充分方可径改并出记。
- 版本简称在凡例中统一交代，如：底本＝宋刊本；甲本＝明嘉靖本；乙本＝清文渊阁本。

## 标点与格式规则

- 以句读为主：古籍整理传统用句读（。、），慎用逗号、问号、叹号等新式标点。
- 引文须核实出处；书名号用《》，篇名用〈〉。
- 分段尊重原书卷次结构；底本原有的大小题、夹注、双行小字须保留并注明。
- 异体字/俗字：原则上保留底本用字，或按凡例统一为通行字并出记。

## 避讳字处理

| 朝代 | 讳例 | 示例 |
| --- | --- | --- |
| 秦 | 避秦始皇"政" | 正月→端月 |
| 汉 | 避汉高祖"邦" | 邦→国 |
| 唐 | 避唐太宗"世民" | 世→代、民→人 |
| 宋 | 避赵匡胤"玄朗" | 玄→元（也见于清代因避康熙讳） |
| 清 | 避清圣祖"玄烨" | 玄→元、炫→眩 |

处理方式：底本原字不动；在凡例中说明避讳情况；确需回改时出校记（如"玄，底本作'元'，系避清讳，今回改"）。

## 点校本成品结构

1. 前言/出版说明（版本源流、整理经过）
2. 凡例（底本、校改、用字、标点体例）
3. 目录
4. 正文（含卷次、篇章）
5. 校勘记（章末注或页下注）
6. 附录（异体字对照表、参考书目）
