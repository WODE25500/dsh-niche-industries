# 蜂群四季管理与病虫害

## 四季管理主线（北温带参考，按当地物候调整）

| 季节 | 关键工作 |
| --- | --- |
| 春（2-4月） | 春繁：紧脾保温、奖励饲喂、治螨（断子期或早春）、换王/育王准备 |
| 夏（5-7月） | 流蜜期：加继箱、控制分蜂热、取蜜（封盖率≥70%）、留足饲料 |
| 秋（8-10月） | 秋繁：培养越冬蜂、断子期彻底治螨、合并弱群、贮备越冬饲料 |
| 冬（11-1月） | 越冬：保温包装、防鼠、留通气孔、少打扰（开箱查"越冬蜂团"） |

## 常见病虫害鉴别

### 蜂螨（狄斯瓦螨/小蜂螨）
- 症状：巢房内白色幼虫体表见红色螨虫；成蜂翅畸形、爬行无力；封盖子脾出现"白头蛹"。
- 确认：掀开封盖子检查幼虫/蛹体表；或用药剂熏蒸后收集落螨计数。
- 处理：断子期（无封盖子）用药最有效；常用甲酸、草酸（有机）、氟胺氰菊酯（化学）；
  注意轮换用药防抗药性；流蜜期禁用药。

### 美洲幼虫腐臭病（AFB，法定检疫病）
- 症状：封盖子脾表面凹陷、穿孔；幼虫尸体呈咖啡色、黏稠拉丝（火柴梗试验阳性）；有腐臭味。
- 处理：烧毁病群与污染蜂具（或深埋），上报当地畜牧兽医部门；禁止用抗生素治疗生产群。

### 欧洲幼虫腐臭病（EFB）
- 症状：幼虫移位、扭曲，尸体呈黄褐色、不拉丝或轻微拉丝；子脾呈"花子"。
- 处理：换箱换脾、断子清巢、加强饲喂；必要时按法规使用土霉素类（非生产期）。

### 爬蜂综合征（综合症，非单一病）
- 症状：大量成年蜂在箱前地面爬行、不能飞。
- 排查顺序：农药中毒（抽搐、吐舌、花粉团）、蜂螨寄生、病毒（如囊状幼虫病）、
  饲料问题、越冬损伤。先做田间与蜂箱双排查，勿盲目用药。

### 囊状幼虫病（中蜂高发）
- 症状：幼虫呈囊状、头部上翘、体色变黄褐，干缩后呈"龙船状"。
- 处理：囚王断子、换脾换箱、加强营养；中蜂可考虑抗病品系。

## 蜂群检查清单（开箱前）

- [ ] 时间：晴天、气温≥15℃、非流蜜高峰午后
- [ ] 装备：面网、手套、喷烟器、起刮刀、备用空脾
- [ ] 观察：巢门口活动量、有无死蜂/爬蜂/盗蜂、有无粪便
- [ ] 提脾：轻提慢放、不压蜂；看子脾（卵虫蛹比例）、蜜粉脾、王台
- [ ] 记录：群势（框数）、王台有无、病征、上次处理

## 蜂蜜采收成熟度判断

- 封盖率：≥70% 的巢房封盖（蜡盖变白）为成熟蜜标志。
- 含水量：取蜜后测波美度/折光仪，≥42 波美度（约 18% 含水）才适合长期存放。
- 取蜜时机：流蜜期晴好天气上午；留足越冬饲料（北方 20-30kg/群）。

## 用药安全

- 只使用当地登记允许的蜂药；遵守休药期与安全间隔（如草酸熏蒸后 7 天内不取蜜）。
- 生产期（流蜜期）禁用药；抗生素一律不得用于生产群。
- 记录用药日期、药名、剂量、群号——符合可追溯要求。
